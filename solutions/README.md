# Solutions

> **Attempt every exercise yourself before you open a solution.** You learn by getting stuck and unstuck. Reading an answer first feels like progress, but it skips the part that builds skill.

When you do open one, compare it with yours:
- Does yours give the same output for every case in the exercise's **Desired output**?
- Does yours handle bad input (letters instead of numbers, values out of range)?
- Is there a simpler way to write something you wrote?

There is often more than one good solution. Yours does not have to match line for line.
